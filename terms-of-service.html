3. The Services

We operate two distinct marketplace applications, described below. Full detail on what data each App accesses and how it is processed is set out in our Privacy Policy, which forms part of these Terms by reference.

3.1 ARBridge for QuickBooks

ARBridge is a HubSpot Marketplace app. For each Customer who installs it, ARBridge reads Customer, Invoice, and Payment records from that Customer's own QuickBooks Desktop company file — via QuickBooks Web Connector, using the qbXML protocol — and writes a derived financial picture into that same Customer's own HubSpot account. It does not aggregate or share data across different Customers.

Aspect How ARBridge Works
Direction One-way: QuickBooks Desktop → HubSpot only
QuickBooks access Read-only, structurally enforced — ARBridge only ever issues qbXML "Query" requests; there is no code path capable of adding, modifying, or deleting anything in a Customer's QuickBooks file
What syncs to HubSpot Company and Contact records (from Customer/billing contact identity), native HubSpot Invoice records (from Invoice/Payment data), and derived fields (AR aging, credit-status flag, lifetime revenue, trailing-12-month revenue, last-payment info)

3.2 Order Issue Alerts

Order Issue Alerts is a Shopify App Store app, embedded in Shopify Admin. For each Customer who installs it, it reads that Customer's own Shopify store data — orders, fulfillments, inventory, and locations — via Shopify's GraphQL Admin API, and produces a nightly AI-summarized digest that surfaces fulfillment delays, inventory mismatches, address-validation issues, and stalled third-party-fulfillment orders in one prioritized list inside Shopify Admin.

Aspect How Order Issue Alerts Works
Shopify access Read-only OAuth scopes only (order, fulfillment, inventory, location, and third-party-fulfillment-order data); Order Issue Alerts does not modify orders, inventory, or fulfillments in Shopify
Detection Real-time Shopify webhooks plus periodic reconciliation scans, covering four exception categories: fulfillment delays, inventory mismatches, address-validation issues, and third-party-fulfillment-service stalls
Digest generation A nightly batch job summarizes open exceptions into a plain-English, prioritized digest using a third-party AI model, displayed inside the merchant's own Shopify Admin
